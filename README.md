# پنل مدیریت هم‌مسیر (React + Vite + TypeScript)

## اجرا (توسعه)
```
npm install
npm run dev          # http://localhost:5173  ← درخواست‌های /api به http://localhost:8000 پراکسی می‌شود
```
بک‌اند را جداگانه اجرا کنید. برای آدرس دیگر: `VITE_PROXY_TARGET=http://IP:8000 npm run dev`

## استقرار
`npm run build` ← پوشه‌ی `dist` را با Nginx سرو کنید و `/api/` را به FastAPI پراکسی کنید:
```
location /api/ { proxy_pass http://127.0.0.1:8000/; }
location /     { root /var/www/hammasir_admin; try_files $uri /index.html; }
```
چون هر دو روی یک دامنه‌اند، CORS لازم نیست. فونت وزیرمتن داخل بسته است (بدون CDN).

## نقشه‌ی آفلاین (PMTiles)
فایل `zanjan.pmtiles` (استخراج‌شده با `pmtiles extract` از ساخت روزانه‌ی Protomaps) را در `public/tiles/` بگذارید؛ نقشه‌ی زنده خودکار از آن می‌خواند و بدون اینترنت هم کار می‌کند. اگر فایل نبود، از OpenStreetMap (آنلاین) استفاده می‌شود. بالای صفحه‌ی نقشه «نقشه‌ی آفلاین / آنلاین» نوشته می‌شود.
- فقط محدوده‌ی استخراج‌شده نقشه دارد؛ بیرون از آن، در حالت آفلاین خالی است.
- در production با Nginx زیر `/tiles/` سرو کنید (Nginx به‌طور پیش‌فرض Range را پشتیبانی می‌کند):
```
location /tiles/ { alias /var/www/hammasir_tiles/; add_header Cache-Control "public, max-age=86400"; }
```
- آدرس دیگر: `VITE_PMTILES_URL`.

## وضعیت (نسخه ۰.۸)
- ورود با نقش مدیر؛ منو بر اساس نقش. داشبورد سفرهای امروز.
- مدیر ارشد: تعریف دانشگاه. مدیر دانشگاه/مدیر ارشد: دانشجویان + بارگذاری گروهی از Excel (پیش‌نمایش، سپس ثبت؛ همه یا هیچ‌کدام).
- قراردادها: تعریف نرخ هر سفر به‌ازای نوع خودرو (اتوبوس/مینی‌بوس/…) برای هر قرارداد.
- گزارش مالی: هزینه = سفرهای انجام‌شده × نرخ نوع خودرو، بازه‌ی تاریخ، جزئیات هر قرارداد، هشدار سفرهای بدون نرخ، خروجی CSV. دانشجو چیزی نمی‌پردازد.
- فرم‌های ساخت/ویرایش/فعال‌سازی: شرکت (فقط مدیر ارشد)، قرارداد، خودرو، راننده، و صفحه‌ی کاربران (مدیر دانشگاه، مسئول حمل‌ونقل، کاربر شرکت، راننده، تغییر رمز، غیرفعال‌سازی). دسترسی‌ها همان قواعد بک‌اند است.
- لیست‌های فقط‌خواندنی: شرکت‌ها، خودروها، رانندگان، سفرها.
- اتصال خودرو و راننده به قرارداد (دکمه‌ی «خودرو و راننده» در قراردادها) ساخته شد.
- شبکه: ایستگاه‌ها (با مختصات)، مسیرها و ایستگاه‌های هر مسیر، سرویس‌ها، برنامه‌ی هفتگی، تولید سفرهای روزانه، تعیین راننده/خودرو (فقط موارد مجاز قرارداد)، لغو سفر.
- نقشه‌ی زنده (Leaflet/OpenStreetMap): خودروی سفرهای فعال هر ۱۰ ثانیه، علامت «قطع» اگر ۲ دقیقه موقعیتی نیامده. آدرس تایل با VITE_TILE_URL قابل تغییر است.
- خرابی‌ها: فهرست باز/همه، تعیین جایگزین، «رفع شد».
- تاریخ‌ها همه شمسی‌اند (انتخاب سال/ماه/روز)؛ مقدار ارسالی به بک‌اند همچنان میلادی ISO است.
- ساخته نشده: انتخاب مختصات روی نقشه، تولید خودکار شبانه‌ی سفرها.

## بک‌اند
`app/api/student_import.py` را اضافه و ثبت کنید (BACKEND_PATCH_ADMIN.md).
رمز اولیه‌ی دانشجویان را مدیر هنگام بارگذاری تعیین می‌کند؛ «تغییر اجباری رمز در اولین ورود» هنوز وجود ندارد.

## تعویض نقشه و جستجوی مکان
- بالای نقشه‌ی زنده و پنجره‌ی «انتخاب موقعیت» کلید «آفلاین | آنلاین» هست. انتخاب در مرورگر ذخیره می‌شود. اگر فایل `zanjan.pmtiles` روی سرور نباشد، گزینه‌ی آفلاین غیرفعال است.
- بیشینه‌ی زوم داده از هدر فایل PMTiles خوانده می‌شود؛ برای جزئیات بیشتر فایل را با `--maxzoom=17` دوباره بسازید.
- جستجو: ابتدا بین ایستگاه‌های ثبت‌شده (آفلاین هم کار می‌کند) و با زدن دکمه از Nominatim هم می‌پرسد. برای مصرف سنگین، سرویس Nominatim خودتان را با `VITE_GEOCODE_URL` بدهید (سیاست استفاده‌ی OSM).

## تنظیمات و پشتیبان‌گیری
- منوی همبرگری کنار دکمه‌ی خروج: پروفایل من (ویرایش نام/تلفن و تغییر رمز)، پشتیبان‌گیری و بازگردانی، درباره ما، ارتباط با ما.
- متن «درباره ما» و اطلاعات تماس را در `src/lib/brand.ts` (`ABOUT_TEXT` و `CONTACT`) بنویسید؛ مقدار خالی نمایش داده نمی‌شود.
- پشتیبان فقط برای مدیر کل و مدیر همان دانشگاه است. فایل `.json.gz` از داده‌های یک دانشگاه ساخته می‌شود (شامل هش رمزها؛ محرمانه نگه دارید).
- بازگردانی از نوع «ادغام» است: رکوردهای فایل اضافه یا جایگزین می‌شوند و چیزی حذف نمی‌شود. ابتدا پیش‌نمایش نشان داده می‌شود.
- در توسعه، پیشوند `backup` باید در پراکسی Vite باشد (هست). در Nginx کل `/api/` پراکسی می‌شود. حجم آپلود (`client_max_body_size`) را متناسب با پشتیبان‌ها (مثلاً `100m`) تنظیم کنید.

## راننده/خودروی پیش‌فرض و تولید شبانه‌ی سفرها (v0.15)

- در «سرویس‌ها ← برنامه‌ی هفتگی» می‌توان راننده و خودروی پیش‌فرض را تعیین کرد (فقط از بین موارد وصل‌شده به قرارداد سرویس).
- تولید سفر روزانه، پیش‌فرض را خودکار تخصیص می‌دهد. شرکت/مدیر هر زمان پیش‌فرض را عوض می‌کند و می‌تواند روی سفرهای آینده‌ی شروع‌نشده هم اعمال کند؛ جایگزین‌های موردی دست‌نخورده می‌مانند.
- اجرای شبانه (روی سرور بک‌اند، پوشه‌ی پروژه): `python -m app.jobs.generate_trips --days 3`
  - cron نمونه: `10 0 * * * cd /path/to/student-transport && /path/to/venv/bin/python -m app.jobs.generate_trips --days 3 >> /var/log/hammasir_trips.log 2>&1`
  - اجرای مکرر امن است (سفر تکراری ساخته نمی‌شود).
